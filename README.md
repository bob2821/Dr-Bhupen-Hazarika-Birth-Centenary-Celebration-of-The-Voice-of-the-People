# Digital Lamp Lighting – Working Mockup

Mobile experience for the **Dr Bhupen Hazarika Birth Centenary Celebration of The Voice of the People**.
Guests scan a QR on the LED wall, enter their name and light a 3D brass lamp on their phone.

**Flow:** Welcome → Enter Your Name → The Lamp Is Lit (personal thank-you)

## Open the mockup
- **On a phone:** open the GitHub Pages link. This is the intended experience.
- **On a tablet or computer:** open the same link; the layout adapts to the screen.

This is a demo build: names are not sent anywhere. The event build connects to the show server.

## Works on
- iPhone and iPad: Safari, Chrome (iOS 15 or newer)
- Android: Chrome, Samsung Internet, Firefox
- Desktop: Chrome, Edge, Safari, Firefox
- Portrait and landscape, from small phones (320 px wide) to large monitors
- Devices that cannot run the 3D lamp are shown a still image of the lit lamp instead

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `digital-lamp-lighting`).
2. Upload `index.html`, `.nojekyll` and this `README.md` to the repository root.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then click **Save**.
4. After about a minute the mockup is live at `https://<your-username>.github.io/digital-lamp-lighting/`.

`index.html` is fully self-contained (images, fonts and the 3D engine are built in), so no other files are needed.
